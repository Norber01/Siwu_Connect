# Siwu Connect

A community platform for the four Siwu-speaking Akpafu towns — Akpafu Odomi, Akpafu Mempeasem,
Akpafu Todzi and Akpafu Adokor — for residents, Ghanaians elsewhere and the diaspora.

**Current stage:** Phase 1 planning. No application code yet.

- Product brief: [`docs/Siwu_Connect_Product_and_Development_Brief.docx`](docs/Siwu_Connect_Product_and_Development_Brief.docx)
- Phase 1 plan: [`docs/PHASE1_PLAN.md`](docs/PHASE1_PLAN.md)
- Project log & open decisions: [`PROJECT_LOG.md`](PROJECT_LOG.md)

Planned stack: React + TypeScript (PWA) on Cloudflare Pages, Firebase Authentication,
Cloud Firestore, a Cloudflare Worker for privileged actions, and Cloudflare R2 for profile photos.
